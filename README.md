# Nadi-9 subtitle agent

An evidence-grounded subtitle decision pipeline with inspectable claims, explicit abstention,
independent verification, and selective correction handling.

Requires Python 3.11 or newer.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
nadi9 --version
pytest
```

Demonstration data in this repository is synthetic and must not be treated as verified
knowledge of Nadi-9.
